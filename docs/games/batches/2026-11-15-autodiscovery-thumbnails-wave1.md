Issue: #8. Branch `feature/games-autodiscovery-thumbnails`, worktree `../brainee-issue-8`, started from `origin/master` `7786386` and rebased onto `19f62e9` (PIN-gated Parents entry; catalog sync). Neither upstream commit touches game folders, the catalog or card components.

## 1. Auto-discovery (task 1)

- `scripts/discover-games.mjs` scans `packages/games/src/<id>/manifest.json` (React), `games/<id>/manifest.json` (scored embedded) and `games/<id>/preview.json` (Explore). The folder name must equal the manifest `id`; a folder must have exactly one of manifest/preview.
- It writes two **gitignored** modules: `packages/game-catalog/src/discovered.generated.ts` (manifest JSON imports, validated by the existing zod schemas) and `packages/games/src/react-games.generated.ts` (each React folder's default-exported `GameDefinition`). They are regenerated by `postinstall`, `pnpm dev`, `pnpm test`, `pnpm typecheck`, `pnpm games:build` and `pnpm check:manifests` (`pnpm games:discover` on its own). See D-38.
- `scripts/build-games.mjs` and `scripts/check-manifests.mjs` no longer name any game. Each embedded folder exports `buildGame(destination)` from its own `build.mjs`, plus an optional `checkAssets(base)` for code-loaded assets (Picture Puzzle's pictures). `scripts/build-tangram.mjs` moved to `games/tangram-tales/build.mjs`.
- **Order** (grid, recommendations fill, `/lab` default): React games first, then embedded; each by `minAge`, then id. Odd One Out stays first.
- `turbo.json` `globalDependencies` include every manifest/preview, so a new folder invalidates cached tests.
- Kept: pinned `sources.lock.json` hash checks, React source budgets, built-asset budgets, HTML/CSS reference checks, `bridge.js` presence.
- **Adding a game now touches only its folder** (plus, for a new e2e spec, the spec regexes in `playwright.config.ts`).

## 2. Thumbnails (task 2)

- Schema: required `thumbnail` on manifests and previews, always `/games/<id>/thumbnail.svg` (`thumbnailUrl(id)` in `@brainee/game-catalog`). The source file sits in the game folder; `games:build` copies it for React and embedded games alike.
- Rules checked by `check:manifests` and `game-catalog/src/thumbnails.test.ts`: exists, ≤ 8 KB (`THUMBNAIL_MAX_BYTES`), `viewBox` 4:3 (160 × 120), no `<text>`, `<image>`, `<script>`, `<style>`, `href`, `url(` or font references. Style: `#F2F1FA` canvas, 1 px `#E6E4F2` frame, `rx` 18, `GAME_PALETTE` colours, no Brainy. Decorative (`aria-hidden`, `alt=""`): the title stays in the card.
- Mechanic shown per game: Odd One Out (3 × 3 grid, one different shape), Continue the Pattern (circle/square row with a gap), Picture Puzzle (picture with a missing jigsaw piece), Tangram Tales (house silhouette from pieces), Rhythm Copycat (four pads, one lit), Secret Message Lab (envelope + symbol slot row with an empty slot), Mirror Grid (two grids mirrored across a dashed line), Magnet Mission Lab (horseshoe magnet and field), Neighborhood Route Planner (map with a dashed route to a pin), Shape Pairs (outline balloons above shapes, one pair linked), Color Boxes (pictures dropping into coloured boxes), Sticker Scene (sticker dragged onto its shadow).
- App (card slot only): `components/child/GameThumbnail.tsx` renders the image with `SkillIcon` as a small badge; locked cards show it at 50 % opacity with a lock. Used by `GameGrid`, `RecommendationCards` (Learn and Entry) and the Explore list. Learn recommendations are a compact row on phones.

## 3. First Explore wave (task 3)

**Owner direction during the batch:** take games from our earlier project (`pecs-game-store-master.zip`, GSP) instead of localizing hard-to-support QLOBE titles. The QLOBE/Sugarizer/H5P/Blockly queue in [external-games.md](../../product/external-games.md) is unchanged and still open.

| Game | id | From GSP | Age | Real input tested |
|---|---|---|---|---|
| Shape Pairs | `shape-pairs` | `phaser-shape-pairs-game` | 4+ | tap a shape, then its balloon → one pair matched |
| Color Boxes | `color-boxes` | `phaser-color-sort-game` | 4+ | drag a picture into the box of its colour → sorted |
| Sticker Scene | `sticker-scene` | `phaser-sticker-scene-game` | 4+ | drag a sticker onto its shadow → placed |

- **Family adapter:** GSP Phaser games share `packages/engine-phaser`, which now also carries GSP `phaser-core`'s sounds, snap, layout, drag-to-target/zone, effects, confetti (`canvas-confetti` 1.9.4, bundled) and `RoundButton`, imported as `@brainee/engine-phaser/<module>`. No per-game wrapper.
- **Declarative Explore metadata** (`preview.json` → `explore`): `family`, `viewport` (`responsive` | `contain` + `aspectRatio`), `orientation`, `audio`, `readiness` (`bridge` | `load`). `ExplorePlayer` applies it: contained letterboxing, a rotate hint, `autoplay 'none'`, and load-based readiness for bridgeless games. Magnet and Neighborhood declare `qlobe`/responsive/landscape/bridge.
- **Explore rules kept:** no `GameResult`, session, wallet, skill or host progress writes (GSP's `progress.load/save` host calls are removed; menu preferences stay in the game's own `localStorage`). Contracts are `<id>@1`. English only: Russian and Kazakh dictionaries and the language picker are gone. Assets are byte-for-byte copies with their MIT/ISC notices; provenance and the archive SHA-256 are in each `CREDITS.md`.
- **Not promoted to scored.** Promotion needs genuine completion/mistake hooks through `GameResult` (one finish, `roundsPerSession`, nothing on leaving midway).
